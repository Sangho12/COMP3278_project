# COMP3278_project

## Running our app on your local computer
### 1. Download the zip folder
### 2. Make sure that you have installed all the packages listed in the requirements.txt
```bash
   pip install -r requirements.txt
```
### 3. Run the python file
```bash
   python app.py
```
